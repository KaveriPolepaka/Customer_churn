# Customer Churn Prediction
### XGBoost Classifier | Accuracy: ~82% | AUC-ROC: ~0.87

Predicts whether a telecom customer will churn using the IBM Telco Customer Churn dataset (7,043 customers, 21 features).

---

## Problem Statement

Customer churn costs telecom companies millions annually. This project builds a machine learning model that identifies high-risk customers **before** they leave, enabling targeted retention campaigns.

---

## Results

| Metric | Score |
|---|---|
| Accuracy | ~82% |
| AUC-ROC | ~0.87 |
| Model | XGBoost Classifier |
| Dataset | IBM Telco Churn (7,043 rows) |

### Top Churn Drivers
1. **Contract type** — Month-to-month customers churn at 42% vs 3% for 2-year contracts
2. **Tenure** — Churned customers average 18 months vs 38 months for retained
3. **Monthly charges** — Higher charges correlate with higher churn
4. **Internet service** — Fiber optic customers churn at 42% vs 19% for DSL
5. **Add-ons** — Customers without security/support add-ons churn more

## Setup & Run

**1. Clone the repo**
```bash
git clone https://github.com/YOUR_USERNAME/churn-predictor.git
cd churn-predictor
```

**2. Create virtual environment**
```bash
python -m venv venv
source venv/bin/activate        # Mac/Linux
venv\Scripts\activate           # Windows
```

**3. Install dependencies**
```bash
pip install -r requirements.txt
```

**4. Download the dataset**

Download `WA_Fn-UseC_-Telco-Customer-Churn.csv` from [Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) and place it in the `data/` folder.

**5. Run notebooks in order**
```bash
jupyter notebook
```
Open and run:
1. `notebooks/01_eda.ipynb`
2. `notebooks/02_preprocessing.ipynb`
3. `notebooks/03_modelling.ipynb`

## Key Techniques Used

- **Exploratory Data Analysis** — distribution plots, churn rate by segment
- **Data Cleaning** — fixing TotalCharges dtype, handling missing values

- **Class Imbalance Handling** — `scale_pos_weight` in XGBoost
