# Customer Churn Prediction

**XGBoost Classifier · SMOTE · SHAP explainability**

Predicts whether a telecom customer will churn, using the IBM Telco Customer Churn dataset (7,043 customers, 21 original features), and explains *why* with SHAP.

## Problem Statement

Customer churn costs telecom companies millions every year. This project builds a machine learning model that identifies high-risk customers before they leave, so the business can run targeted retention campaigns.

## Results

Evaluated on a held-out test set of 1,409 customers (stratified 80/20 split, `random_state=42`). The exact numbers from each run are saved to `models/metrics.json`.

| Metric | Score |
|---|---|
| Accuracy | 76.8% |
| AUC-ROC | 0.834 |
| Precision (churn class) | 55.6% |
| Recall (churn class) | 62.8% |
| F1 (churn class) | 0.590 |
| Model | XGBoost Classifier |
| Imbalance handling | SMOTE (training set only) |

SMOTE grows the training set from 5,634 to 8,278 rows (balanced classes); the test set stays untouched at 1,409 rows. Accuracy is lower than a plain model would give because SMOTE deliberately trades some accuracy for higher recall on churners.

**Why recall matters most:** only 26.5% of customers churn, so accuracy alone is misleading. Recall measures how many of the customers who really leave the model catches. Missing a churner costs more than sending a retention offer to someone who would have stayed.

## Key Findings from EDA

| Finding | Detail |
|---|---|
| Class imbalance | 73.5% retained vs 26.5% churned |
| Contract type | Month-to-month customers churn at ~42%, vs ~11% for 1-year and ~3% for 2-year contracts |
| Tenure | Churned customers average 18 months of tenure vs 38 months for retained customers |
| Monthly charges | Higher charges correlate with higher churn |
| Internet service | Fiber optic customers churn at ~42% vs ~19% for DSL |

The SHAP plots in `images/` show which features drive the model's predictions and in which direction.

## Techniques Used

- **Exploratory Data Analysis** — distribution plots, churn rate by segment
- **Data Cleaning** — fixed `TotalCharges` data type (11 blank values for zero-tenure customers), dropped `customerID`
- **Feature Engineering** — created `AvgMonthlySpend` (total charges ÷ tenure), `NumAddOns` (count of add-on services) and `TenureGroup` (0–12, 13–36, 37+ months), plus binary and one-hot encoding
- **Class Imbalance Handling** — SMOTE applied to the training set only, so synthetic points never leak into the test set
- **Model** — XGBoost (200 trees, max depth 4, learning rate 0.1)
- **Model Comparison** — SMOTE compared against XGBoost's `scale_pos_weight` on the same test set
- **Evaluation** — accuracy, AUC-ROC, precision, recall, F1, confusion matrix, ROC curve
- **Explainability** — XGBoost feature importance and SHAP (bar and beeswarm plots)

## Setup & Run

1. **Clone the repo**
   ```bash
   git clone https://github.com/KaveriPolepaka/Customer_churn.git
   cd Customer_churn
   ```
2. **Create a virtual environment**
   ```bash
   python -m venv venv
   source venv/bin/activate        # Mac/Linux
   venv\Scripts\activate           # Windows
   ```
3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```
4. **Download the dataset** — get `WA_Fn-UseC_-Telco-Customer-Churn.csv` from [Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) and place it in the `data/` folder.
5. **Run the notebooks in order**
   ```bash
   jupyter notebook
   ```
   Open and run `notebooks/01_eda.ipynb`, then `02_preprocessing.ipynb`, then `03_modelling.ipynb`.

## Dataset

IBM Telco Customer Churn dataset from Kaggle: 7,043 customers, 21 features (demographics, services, billing). Target: `Churn` (Yes/No).
